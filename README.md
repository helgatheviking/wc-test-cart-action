# Test Cart Item Action

An example plugin demonstrating how to register custom cart item actions in WooCommerce Blocks using the registry pattern proposed in https://github.com/woocommerce/woocommerce/pull/63296.

## Description

This plugin adds a "Custom Action" button to every item in the WooCommerce Cart block. When clicked, it displays an alert with the cart item key. This serves as a minimal working example of the Cart Item Actions registry system.

## Requirements

- WordPress 6.0 or higher
- WooCommerce 9.0 or higher
- Node.js and npm (for building)

## Installation

### 1. Install Dependencies

Navigate to the plugin directory and install npm dependencies:

```bash
cd wp-content/plugins/test-cart-action
npm install
```

### 2. Build the Plugin

Build the JavaScript assets:

```bash
npm run build
```

For development with auto-rebuild on file changes:

```bash
npm run start
```

### 3. Activate the Plugin

1. Go to WordPress Admin → Plugins
2. Find "Test Cart Item Action"
3. Click "Activate"

## Usage

Once activated, the plugin automatically registers a custom cart item action. To see it in action:

1. Add any product to your cart
2. Navigate to the Cart block (not the shortcode-based cart)
3. You'll see a "Custom Action" button for each cart item
4. Click the button to see an alert with the cart item key

## How It Works

The plugin demonstrates the Cart Item Actions registry pattern:

1. **Registration**: Uses `registerCartItemAction()` from `@woocommerce/blocks-checkout`
2. **Integration**: Implements `IntegrationInterface` to register with WooCommerce Blocks
3. **Rendering**: The registered component is automatically rendered for each cart line item

## Customization

To modify the action button:

1. Edit `src/frontend.js`
2. Rebuild with `npm run build` or have `npm run start` running
3. Refresh your browser

### Example: Conditional Rendering

```javascript
const MyCartItemAction = ( { lineItem, cart } ) => {
	// Only show for products over $50
	if ( lineItem.prices.price < 5000 ) {
		return null;
	}

	const handleClick = () => {
		alert( 'Action clicked for item: ' + lineItem.key );
	};

	return (
		<button
			className="my-custom-action"
			onClick={ handleClick }
		>
			{ __( 'Custom Action', 'test-cart-action' ) }
		</button>
	);
};
```
